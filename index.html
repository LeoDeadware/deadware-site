Native ports for Apple Silicon

Old games, reborn as real Mac apps

Deadware rebuilds games from the original Xbox and classic PCs into native apps for M-series Macs. The game's code is recompiled for your Mac. You bring your own copy; the port is free.

How it works

  1. You provide the game: your disc image or your GOG installer. We never host game files.
  2. The port recompiles the game's code ahead of time into native Apple Silicon code.
  3. Graphics, sound and controllers run on Metal and SDL3, with widescreen, 60 fps and HD where the game allows.
  4. The result is a regular app in your Applications folder.

No game files or game code are hosted here or on GitHub: every port builds from your own copy.

Deadware is a fan project. It is not affiliated with or endorsed by the publishers or trademark owners of the games; their names are used only to say which game a port runs.
